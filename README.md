# 아이다움 (IDAHUM)

> 아이디어를 모으고 다듬어서 실제 서비스로 만들어 가는 프로젝트

## 현재 단계

- [x] 저장소 만들기
- [ ] 아이디어 모으기 → [`ideas/`](ideas/)
- [ ] 하나 골라서 구체화하기
- [ ] 첫 버전(MVP) 만들기

## 폴더 구조

```
ideas/          아이디어 메모 (한 아이디어당 파일 하나)
  _template.md  새 아이디어를 쓸 때 복사해서 쓰는 양식
docs/           결정 사항, 회의/작업 기록
```
