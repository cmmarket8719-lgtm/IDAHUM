# 메인 페이지 컨셉 v1 — "제품이 주인공"

- 작성일: 2026-11-23
- 시안 파일: [`site/index.html`](../site/index.html) (브라우저로 열면 바로 보임)
- 참고 사이트: [보바 vova.co.kr](https://vova.co.kr/)

## 왜 바꾸나

지금 idahum.kr 메인 배너는 쿠폰, 카카오 채널 같은 **이벤트 내용만** 보여서 무엇을 파는 회사인지 바로 알기 어렵다.
보바처럼 **메인 배너에 제품을 크게** 보여줘서 첫 화면에서 바로 상품이 눈에 들어오게 한다.

## 보바에서 가져온 것

| 보바 | 아이다움 시안에 적용 |
|---|---|
| 배너마다 제품 하나를 크게 배치 + `[NEW ARRIVAL]` 태그 + 굵은 제목 + 검정 "자세히 보기" 버튼 | 배너 5장, 각각 제품 사진 3장 콜라주 + 태그 + 제목 + 버튼 |
| 파스텔 배경 | 배너마다 다른 파스텔 색 (핑크/민트/옐로/스카이/라벤더) |
| 배너 번호 표시 `4 / 15` | `1 / 5` 표시, 좌우 화살표, 진행 막대 |
| 동그란 카테고리 바로가기 | BEST · 캐릭터 마스크 · 0~3세 윙타입 · KF94 · 토이 · 어린이용품 |
| 탭으로 나뉜 상품 목록 | 베스트 / 마스크 / 토이 / 어린이용품 탭 |
| "Perfect for your life · SHOP NOW" 제품 스토리 배너 | 캐릭터 마스크, 토이 스토리 배너 |

## 메인 배너 5장

1. **NEW ARRIVAL** — 새로 나온 캐릭터 마스크 10매입 4종
2. **0~3세 전용** — 우리 아기의 첫 마스크, 윙타입 + 40매입 선물 세트
3. **TOY 신상** — 픽셀자석블럭, 공룡탐험대, 메탈중장비트럭
4. **KF94 · KC인증** — 사계절 호흡기 보호 KF94 키즈 마스크
5. **우리집 상비템** — 실리콘 투약병, 해열시트

## 페이지 순서

1. 띠배너 (첫 구매 쿠폰): 이벤트는 여기 한 줄로만
2. 헤더 + 메뉴 (BEST / 마스크 / 토이 / 어린이용품 / EVENT)
3. **메인 배너 (제품 중심)**
4. 카테고리 바로가기 (원형 아이콘)
5. 아이다움 베스트 (탭 상품 목록)
6. 제품 스토리 배너 2개
7. 아이다움이 지키는 약속 (국내산 / KC 인증 / 연령별 사이즈 / 상담)
8. 푸터

## 시안의 한계 (실제 적용 전 필요한 것)

- 상품 사진은 지금 쇼핑몰 썸네일을 그대로 써서 배경이 있다. 보바처럼 **누끼(배경 제거) 제품 사진**이 있으면 훨씬 깔끔해진다.
- 배너 문구는 임시로 쓴 것이라 확인이 필요하다.
- 실제 사이트에 적용하려면 Cafe24 스킨(디자인) 편집 또는 배너 이미지 제작이 필요하다.
