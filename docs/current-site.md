1. 상단 띠배너: 회원가입+SMS 수신동의 시 첫 구매 3,000원 쿠폰
2. 헤더: 햄버거 메뉴 / IDAHUM 로고(일러스트) / 검색
3. 메인 슬라이드 배너 3장 (예: 카카오톡 채널 추가 시 쿠폰)
4. **아이다움 NEW 신상품**: 마스크, 풀백카, RC카, 블럭, 피규어 등이 섞여 있음
5. **아이다움 캐릭터 마스크**: KC인증, 유아부터 어린이까지
6. **NEW 유아 윙타입 마스크**: 0~3세 전용 새부리형 캐릭터
7. **KF94 새부리형 컬러 마스크**: 초소형/소형 사이즈
8. 우리 아기의 첫 마스크 (3세 미만 문구)
9. **키즈 안전우산**: 자외선 차단, 빛 반사
10. 사계절 호흡기 보호 KF94 (문구)
11. REVIEW
12. 푸터: 회사 정보, 고객센터, 이용약관 등
13. 모바일 하단 고정 바: 메뉴 / 검색 / 홈 / 장바구니 / 마이쇼핑

## 지금 사이트의 문제점 (첫인상 기준)

- **정체성이 흐림**: 사이트 이름은 "아이다움"인데 메인 페이지 대부분이 마스크라서 마스크 판매몰처럼 보임
- **같은 상품이 반복됨**: 같은 캐릭터 마스크가 신상품, 캐릭터 마스크, 윙타입 영역에 여러 번 나옴
- **신상품 영역에 성격이 다른 상품이 섞임**: 마스크, 수입차 풀백카, 바이크
- **브랜드 이야기가 없음**: 아이다움이 어떤 회사이고 무엇을 중요하게 여기는지 보여주는 영역이 없음
- 메인 배너가 쿠폰 위주라서 브랜드 첫인상이 약함
